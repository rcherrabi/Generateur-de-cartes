# G-n-rateur-de-cartes
Outil PyQGIS d'automatisation cartographique et d'habillage normé de dossiers réglementaires (PC1, CER, CETI). Il ajuste automatiquement l'emprise, l'échelle et le format (A4/A3), intègre la charte d'entreprise et trace interactivement les axes de prises de vue, réduisant les temps de production de 30 min à quelques secondes
